# 📈 模块化双均线量化回测系统

**开发者：** 吴鸿鸣 (ID: 241733402)
**项目定位：** 基于 Python 的轻量级量化策略运维与可视化平台

---

## 🚀 项目亮点
本系统通过对原始量化脚本的**工程化重构**，实现了逻辑与数据的彻底解耦。
- **模块化架构：** 拆分配置(Config)、策略(Strategy)、调度(Main)与展示(App)，便于快速扩展新算法。
- **自动化预热处理：** 自动剔除均线计算初期的 `NaN` 数据，确保回测信号从有效交易日开始。
- **交互式可视化：** 基于 Streamlit 搭建 Web 界面，支持动态调整参数（如 MA 窗口值）并实时观察夏普比率变化。
- **环境自适应：** 统一使用 `utf-8-sig` 编码，完美解决 Excel 与 Python 之间的中文乱码问题。

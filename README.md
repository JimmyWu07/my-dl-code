# QuantResearchLab

**开发者：** Jimy
**项目定位：** 基于 Python 的量化策略研究与回测平台

---

## 项目亮点

本系统通过对原始量化脚本的**工程化重构**，实现了逻辑与数据的彻底解耦。

- **模块化架构：** 拆分配置(Config)、策略(Strategy)、调度(Main)与展示(App)，便于快速扩展新算法。
- **ADX 趋势过滤：** 在双均线金叉/死叉信号基础上加入 ADX 过滤，只在市场有明显趋势时开仓，减少震荡市中的假突破信号。
- **防冗余仓控：** 仓位切换采用状态机逻辑，连续同向信号不会重复触发交易，避免无效换仓带来的手续费损耗。
- **交互式可视化：** 基于 Streamlit 搭建 Web 界面，支持动态调整参数（如 MA 窗口值）并实时观察夏普比率变化。
- **环境自适应：** 统一使用 `utf-8-sig` 编码，完美解决 Excel 与 Python 之间的中文乱码问题。

## 策略逻辑

### 双均线交叉

- **买入信号（金叉）：** MA_short 上穿 MA_long（前一日 ≤，当日 >）
- **卖出信号（死叉）：** MA_short 下穿 MA_long（前一日 ≥，当日 <）

### ADX 趋势过滤器

ADX（Average Directional Index）衡量市场趋势强度，数值越高表示趋势越明显。

- 信号生成时要求 **ADX > 阈值**（默认 12）
- 震荡市 ADX 走低，假金叉/死叉被自动滤除
- 阈值可在 `generate_signals(adx_threshold=...)` 中调整：
  - **降低阈值（8~12）：** 更多交易信号，适合趋势明显的市场
  - **提高阈值（20~25）：** 更严格过滤，适合震荡频繁的标的

### 仓位状态机

仓位只在信号方向与当前状态不一致时才切换：
- 空仓 + 买入信号 → 开多（position: 0 → 1）
- 持仓 + 卖出信号 → 平仓（position: 1 → 0）
- 连续同向信号不重复触发

### 手续费

每笔实际换仓交易扣除 0.03% 佣金，仅在实际持仓变化时计算，无效信号不产生费用。

# 📈 QuantResearchLab

**开发者：**Jimy
**项目定位：** 基于 Python 的量化策略研究与回测平台

---

## 🚀 项目亮点

本系统通过对原始量化脚本的**工程化重构**，实现了逻辑与数据的彻底解耦。

- **模块化架构：** 拆分配置(Config)、策略(Strategy)、调度(Main)与展示(App)，便于快速扩展新算法。
- **自动化预热处理：** 自动剔除均线计算初期的 `NaN` 数据，确保回测信号从有效交易日开始。
- **交互式可视化：** 基于 Streamlit 搭建 Web 界面，支持动态调整参数（如 MA 窗口值）并实时观察夏普比率变化。
- **环境自适应：** 统一使用 `utf-8-sig` 编码，完美解决 Excel 与 Python 之间的中文乱码问题。

## 📂 目录结构说明

```text
py/
├── main.py             # 系统指挥官：执行自动化回测任务
├── config.py           # 环境管家：管理全局路径与策略参数
├── app.py              # 可视化中心：Streamlit 交互式网页界面
├── normal_market.csv   # 核心数据：常规市场行情数据集
├── README.md           # 项目说明文档
└── utils/              # 工具库
    └── strategy.py     # 核心算法引擎：封装双均线策略类
```

- **双均线的本质假设：一旦趋势形成，会持续一段时间。
- **所以它赚钱的行情 = 趋势流畅、回调小
- **它亏钱的行情 = 震荡、频繁反转、毛刺多
